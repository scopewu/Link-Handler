    User Guide

    Learn what the extension does and what each setting means

    Overview

    The extension processes links on every page automatically in this order: unwrap redirect links, remove same-origin target="_blank", and clean tracking parameters. It only modifies links, not page behavior.

    General Settings

    These switches control the three main features globally.

    • Open same-site links in same tab — When enabled, links pointing to the same website (including relative URLs) will have target="_blank" removed and open in the current tab. Cross-site links are not affected.
    • Enable redirect unwrapping — Global switch. When on, redirect links are replaced with the real destination according to the rules on the Redirects tab. When off, all redirect rules are ignored.
    • Enable tracking cleanup — Global switch. When on, tracking attributes and URL parameters are removed according to the rules on the Tracking tab. When off, all tracking rules are ignored.

    Redirect Rules

    Each rule matches redirect links on a given domain and extracts the real URL from a query parameter. Common sites like Juejin, Zhihu, Weibo are built in, and you can add custom rules.

    • Domain — The domain to match (suffix match). For example, weibo.cn also matches www.weibo.cn.
    • Parameter — The query parameter that carries the real URL, such as target or url. The value is decoded and assigned as the new link.
    • Path prefix — Optional. Only applies when the path matches this prefix, used when only certain paths are redirect pages (e.g. jianshu.com/go).
    • Enabled — Temporarily disable the rule without deleting it.
    • Description — A note shown only for your reference.

    Tracking Cleanup Rules

    Each rule matches a domain and performs three kinds of cleanup on its links. Common sites like Bilibili, Weibo, and Zhihu are built in.

    • Remove attributes — HTML attributes to remove from the link element, such as data-spmid or suda-uatrack.
    • Prevent click rewrite — Block the page from rewriting the link on click, forcing direct navigation instead of a tracked redirect.
    • Clean URL params — Query parameters to remove from the link URL, such as utm_source or spm_id_from. Enter * to remove all parameters. Keep functional parameters like p and t out of this list.
    • Enabled — Temporarily disable the rule without deleting it.
    • Description — A note shown only for your reference.

    Whitelist

    Websites on the whitelist are skipped entirely. Matching uses domain suffixes: adding example.com also covers www.example.com and sub.example.com. You can also add or remove the current site from the popup.

    Backup & Restore

    • Export downloads the current configuration (diff from built-in rules) as a JSON file for migration or backup.
    • Import restores a previously exported JSON file and overwrites all current custom settings.
    • Reset clears all custom rules, overrides, and whitelist changes and restores factory defaults.

    About built-in rules

    Config is stored as a diff against built-in rules, so new or corrected built-in rules automatically take effect after the extension updates unless you modified or removed them.
